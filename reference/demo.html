The card below runs inside a sandboxed iframe. Everything it can do goes through the five entry points on window.card: the counter keeps its value in host-held state, the button calls a tool binding the manifest declares, and the panel underneath shows the result the host sent back.

The card holds none of that itself. State lives out here, keyed by the card's id, in the memory store this page passes in; swap in the local storage store and the same card survives a reload without changing a line of its markup.
