# 让你的 Agent 支持 Showcard

[English](host-integration.md) · [项目入口](../README.zh.md) · [验证你的宿主](testing.zh.md)

先运行最小示例，再把接入点替换成你应用自己的服务。参考实现是 L1 起点，
不包含完整 Agent、插件系统、权限服务或生产后端。

## 跑通接入示例

```sh
npm ci
npm run demo
```

默认监听 `127.0.0.1:8787`，可用 `npm run demo -- --port 8788` 指定端口，Ctrl+C 停止。
服务只提供明确列出的文件和一个已挂载卡片包，不是任意文件服务器或外部网络代理。

| 文件 | 运行位置 | 职责 |
| --- | --- | --- |
| `examples/host/server.mjs` | Node | 提供宿主页、浏览器模块、初始化数据和带实例路径的卡片资源 |
| `examples/host/browser-host.mjs` | 浏览器宿主页 | 加载卡片，绑定身份和状态存储，连接示例工具 |
| `examples/host/card/index.html` | 隔离 iframe | 呈现与编辑数据，请求已声明工具 |
| `reference/src/host.js` | 浏览器 | 分发请求并返回结构化信封 |
| `reference/src/serve.js` | 服务端集成层 | 按实例路径和安全策略提供入口及相对资源 |

示例在宿主浏览器的 localStorage 中按稳定卡片 ID 存储状态。数据属于当前浏览器与
origin，改端口就会改变 origin。产品宿主可以用相同的 `get(cardId)` / `set(cardId, state)`
接口接自己的数据库。重新挂载同一实体沿用 ID，导入分享包则分配新 ID。

## 按数据流接入

1. 在导入或铸造边界校验包，并分配实体身份。
2. 用实例专属 URL 空间提供入口与资产，在作者脚本之前注入运行时，应用包服务器生成的 CSP。
3. 仅在实体尚无保存状态时，用快照显式初始化；不能每次挂载都覆盖用户状态。
4. 创建隔离 iframe，仅接受来自该实例窗口的请求；回显 `requestId`，统一返回成功或失败信封。
5. 对照静态 manifest 解析绑定，经过宿主授权后执行；不能把卡片输入解释成任意后端工具调用。
6. 按实体身份保存数据；卸载时释放监听和订阅，按实体生命周期决定数据保留与清理。

示例只允许无副作用的 `demo.time.now`，由浏览器宿主回调返回 ISO 时间戳，演示工具边界。
持凭据工具、文件写入等能力应放在可信后端网关；凭据**禁止**进入卡片或浏览器代码。

## 参考实现提供什么，产品还要接什么

| 领域 | 参考实现 / 示例 | 产品宿主负责 |
| --- | --- | --- |
| 呈现与资源 | 隔离挂载、实例包路径、Range/ETag | 布局、尺寸标记、主题、加载报错与实例销毁 |
| 状态 | 按 ID 的接口、内存与 localStorage 实现、64 KiB 预算 | 数据库存储、归属、恢复、显式初始化 |
| 工具请求 | manifest 绑定查找、`executeBinding` 接口 | 可信工具表、输入校验、授权、拒绝与撤销 |
| 直接网络访问 | 默认拒绝的实例 CSP | 运行时权限界面与按实例授予的主机权限，不开放任意代理 |
| 会话事件 | 基础消息形状与接收回执 | 真正的会话路由、用户意图、无目标时明确失败 |
| 导入导出 | 包服务与运行时注入能力 | 快照、ZIP、完整资产、新导入身份与重置授权 |
| 钉住与生命周期 | 规范有定义 | 常驻实体创建或分叉、实例独立与清理 |
| 宿主数据与活动记录 | 已说明的可选扩展 | 仅在实现后声明可用，其他宿主仍应能正常使用卡片 |

参考分发器为一致性检查提供 `emit` 消息形状的接收回执，不会把事件真正送进 Agent
会话。产品必须接通投递后再声明可用，或明确报告不可用。

## 权限与生命周期

凭据留在宿主。工具声明限制卡片可请求什么，不代表授权。授权按实体与声明中的具体对象保存，
在声明版本变化等规定条件下撤销，导入时重置信任。钉住不能绕过授权。
卡片可以在对话结束后保留，但未呈现的卡片不执行代码；调度或后台工作是另一项宿主能力，
不能从“持久化”推导出来。

按[一致性验证指南](testing.zh.md)检查协议行为；L2 授权和 L3 生命周期、导出等职责，
还需要宿主侧测试与人工复核。L1 通过不是生产安全的完整认证。
